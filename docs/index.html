ClaudeLauncher

Ein Klick im Finder öffnet Claude Code im Terminal — mit der Anthropic-API oder einem lokalen LLM (Ollama / LM Studio). Eingebauter Proxy übersetzt Tool-Use-Calls bidirektional.

Download für macOS
Kostenlos · Open Source · Apple Silicon, macOS 14+
Quellcode auf GitHub · Alle Releases

Warum?

Schneller Zugriff auf Claude Code, Wechsel zwischen API und lokalen Modellen ohne Umweg über Terminals und Konfigurations-Files.

⌁

Finder-Toolbar-Picker

Ein Claude ▾-Button in der Finder-Toolbar. Klick → Popup mit allen Verbindungen, Default zuoberst. Auswahl → Terminal öffnet am aktuellen Pfad.

↹

API ↔ Lokal nach Bedarf

Anthropic-API für ernsthafte Arbeit, Ollama oder LM Studio für lokale Experimente — beides in derselben App, ein Klick zum Wechseln.

⚙

Tool-Use-Translation

Eingebauter HTTP-Proxy übersetzt Anthropic-Format ↔ OpenAI-Function-Calling. Bash, Read, Edit funktionieren auch gegen lokale Modelle.

∅

Keine Dependencies

Reines Swift, keine Node/Python-Runtimes. Eine 524 KB DMG, in /Applications ziehen, fertig.

↻

Auto-Sync

Connection hinzugefügt, umbenannt oder gelöscht? Quick Actions und Toolbar-Wrapper aktualisieren sich von selbst.

⊞

Quick Actions

Rechtsklick auf einen Ordner → eine Quick Action pro Verbindung. Native macOS-Integration via Automator-Workflows.

Installation in 3 Schritten

Voraussetzung: macOS 14 (Sonoma) oder neuer auf Apple Silicon. Claude Code CLI installiert.

DMG herunterladen und öffnen

ClaudeLauncher-1.0.dmg doppelklicken — Volume mountet sich automatisch.

App in /Applications ziehen

Im DMG-Fenster ClaudeLauncher.app auf den Applications-Symlink ziehen. Beim ersten Start: Rechtsklick auf die App → Öffnen → bestätigen (Gatekeeper, weil ad-hoc-signiert).

Verbindungen anlegen, Toolbar einbauen

Im Settings-UI eine Verbindung hinzufügen (API-Key oder lokaler Endpoint), als Default markieren, dann unten Installieren → In Finder-Toolbar einfügen. Finder restartet kurz, der Claude ▾-Button erscheint in jedem Finder-Fenster.
